UR10e Collision-Aware Motion Planning

Collision-free motion planning for the UR10e robotic arm using RRT-Connect within a Unity – ROS Noetic – MoveIt simulation pipeline.

The system performs collision-aware four-phase pick-and-place tasks in semi-static environments.

Key Features:
- RRT-Connect motion planning (OMPL)
- Planning-time collision checking (FCL)
- Unity–ROS bidirectional communication
- Four-phase pick-and-place strategy
- Physics-based gripper control

Tech Stack:
- Unity 2021.3 LTS
- ROS Noetic (Ubuntu 20.04)
- MoveIt + OMPL
- Python (ROS)
- C# (Unity)
